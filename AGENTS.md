# Repository instructions

- Treat [ITEM_CATALOG.md](ITEM_CATALOG.md) as the owner-approved balance reference for existing ships, upgrades, boosts, items, currencies, recipes, crates, and drop odds.
- Change an existing catalogue entry or its corresponding in-game behaviour only when the owner explicitly requests that change. Apply only their requested changes and update the catalogue and game together.
- Add catalogue entries for new obtainable content. Keep existing entries unless the owner explicitly requests removal.
